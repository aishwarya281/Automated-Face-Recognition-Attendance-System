# Automated Face Recognition Attendance System 🎓📸

An **AI-based attendance management system** that automatically marks student attendance using **face recognition**.
The system captures student faces through a webcam, compares them with the trained dataset, and records attendance automatically.

---

## 🚀 Features

* 👤 Student registration with face dataset creation
* 🧠 Face recognition using machine learning
* 📷 Real-time attendance marking via webcam
* 🏫 Classroom management system
* 📊 Attendance records management
* 💾 Attendance storage using database

## ⚙️ How It Works

1. Create a classroom in the system.
2. Add students and capture their face images using webcam.
3. Images are processed and stored as a dataset.
4. The ML model encodes facial features.
5. During attendance, the system detects faces and matches them with stored encodings.
6. If a match is found, attendance is marked automatically.

## 🖥 Installation & Setup

### 1️⃣ Clone the repository


git clone https://github.com/aishwarya281/Automated-Face-Recognition-Attendance-System.git


### 2️⃣ Install frontend dependencies



npm install
npm run dev


### 3️⃣ Start backend server

npm install
nodemon index.js

### 4️⃣ Run ML service


cd Automated-Face-Recognition-Attendance-System/env/Scripts/activate
cd Automated-Face-Recognition-Attendance-SystemL/env
pip install -r requirements.txt
cd Automated-Face-Recognition-Attendance-System/env/AttendanceSystem
python manage.py runserver
